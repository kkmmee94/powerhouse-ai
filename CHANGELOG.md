# Changelog

All notable changes are documented here. This project follows semantic versioning while recognizing
that `0.x` releases may change interfaces.

## 0.1.0 - 2026-07-27

Initial experimental release:

- local OpenAI-compatible model client and Windows/NVIDIA llama.cpp setup
- project-scoped SQLite memory and FTS5 document retrieval
- deterministic routing, planning, specialist stages, synthesis, and verification
- safe calculator and unit conversion tools
- disabled-by-default trusted Python execution
- FastAPI and Typer interfaces
- reproducible tests and local benchmark harness
